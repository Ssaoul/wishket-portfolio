단계기간작업산출물
1. 착수·NDA착수 즉시 (0.5일)보안 서약서 작성, 대상 실행 파일·툴 체인 정보 수령, 진단 범위·목표 수준 합의NDA, 진단 범위 확정서, 강도 목표 기준선
2. 1차 진단1~2일화이트박스 없이 배포 바이너리 대상 정적/동적 분석, 함수별 강도·평문 노출·자동 복원 재현함수별 취약 지점 리스트, 근거 수치가 포함된 1차 진단 리포트(화상 공유)
3. 심층 분석·방법론 자문 (필요시)2~4일핵심 함수 심층 리버싱, 상용 사례 비교, 적합 툴 체인·보호 등급 설계 제안개선 방법론서, 함수 등급화 표, 권장 툴 체인·아키텍처 자문
4. 검증·이관1일개선안 적용 방향 리뷰, 회귀 측정 스코어카드 세팅 가이드, 내부 개발자 인수인계최종 자문 회의 자료, 강도 측정 체계 가이드, 후속 조치 체크리스트

코드 분석·리버싱 자체는 읽기 전용이므로 원본 바이너리·소스를 변조하지 않으며, 모든 분석은 전달받은 사본으로만 수행합니다. 되돌릴 수 없는 유일한 행위는 코드·실행 파일 열람이므로 NDA 체결 전에는 어떤 자료도 수령하지 않고, 분석 종료 시 전달 자료·중간 산출물을 합의된 절차로 파기합니다. 개선안(가상화·안티 디버깅 삽입)은 제안·자문 단계까지만 진행하며 실제 빌드 적용은 내부 개발자가 별도 브랜치에서 수행하도록 남겨, 원본 빌드로 언제든 롤백할 수 있게 합니다.
