문의 없이 보는 접수 현황

접수 상태는 구글 드라이브 엑셀에 갇혀 있고, 거래처는 매번 전화로 물어봅니다. 관리자가 한 곳에 입력하면 거래처는 자기 건만 로그인해서 봅니다. 인터넷·렌탈·휴대폰 세 갈래를 같은 원장으로 묶었습니다.

3종
접수 메뉴 (인터넷·렌탈·휴대폰)
4단계
진행 상태 (접수중→심사→완료→취소)
거래처별
데이터 분리 (공용 화면 없음)
월 1회
정산 마감 · 확정 후 잠금

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.

이용 흐름

사용자가 하는 일이 끊기지 않는다

로그인
관리자가 발급한 거래처 계정으로 접속한다. 첫 로그인 시 비밀번호를 변경한다.
메뉴 선택
인터넷 / 렌탈 / 휴대폰 중 볼 메뉴를 고르고 기간·상태로 걸러낸다.
접수내역 확인
자사 접수 건 목록에서 접수번호를 눌러 진행 상태와 상태 변경 이력을 본다.
정산 내역 확인
월별 정산 탭에서 확정·예정·차감 건을 나눠 보고, 이견이 있으면 이의 신청을 남긴다.
내역 내려받기
조회한 기간의 접수·정산 내역을 엑셀로 내려받는다. 기존 엑셀 관리 습관을 끊지 않게 둔다.
