근거 — 영문 24개 URL 중 19개(79%)의 description 이 국문과 동일 문자열. hreflang 태그는 0건.

조치 — 티켓 번호로 단일화하고 상충 3건은 최신 차수 기준으로 담당자 확인 후 확정. 확인 전에는 보류 상태 유지.
