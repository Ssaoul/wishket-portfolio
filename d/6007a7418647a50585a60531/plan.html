1. 인수·복원 리허설1~2주차백업 아카이브·DB 덤프 인수, 스테이징 복원, 파일 수·용량·행수 3중 대조. 누락분은 구 환경에서 재수급복원 대조표, 누락·불일치 목록(미해결 항목 포함)
2. 환경 대기업 고객사화3~5주차PHP 7.4 경유 8.2 호환성 수정, 관리 도구 접근 통제, 첨부 저장소 분리, 취약 항목 조치변경 내역서, 조치 전후 점검 결과, 미조치 사유서
3. 전환(컷오버)6주차 · 평가 일정 비수기 주말 새벽최종 동기화 → DNS 전환 → SSL 적용 → 로그인·업로드·문서제출 경로 실사용 확인전환 체크리스트(서명본), 전환 완료 보고 1쪽
4. 정기 운영전환 후 연중보안 패치, 외형 감시, 장애 대응, 평가 시즌 사전 점검, 월간 보고월간 운영 보고(비전문 담당자용 1쪽) + 연간 점검 요약

되돌리기 어려운 작업은 세 가지입니다 — DNS 전환, 신규 DB로의 최종 동기화, 기존 렌탈 서버 반납. 전환 전 DNS TTL을 300초로 낮춰 두고 구 서버를 읽기 전용으로 30일간 살려 두므로, 문제가 보이면 5분 내 원복하고 그 사이 들어온 제출 건은 대조표로 수동 이관합니다. 구 서버 반납은 전환 후 30일 무사고와 담당자 확인 서명을 받은 뒤에만 진행하며, 반납 직전 전체 스냅샷을 별도 매체에 한 부 더 보관합니다.
