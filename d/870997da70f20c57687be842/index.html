제품 상세 페이지에 구조화 데이터(Product/Organization) 없음높음진단 코드 SD-01. 수집한 제품 페이지 148개 중 JSON-LD 스키마 출력 0개. 고도몰 기본 스킨의 goods_view 템플릿이 메타 태그만 출력하고 schema.org 마크업을 포함하지 않음.
동일 상품이 파라미터 URL 4종으로 중복 색인높음진단 코드 IDX-03. 대표 상품 1건에 ?cate=/?page=/?sort=/? 조합으로 서로 다른 URL 4개가 색인. canonical 태그 미선언. 색인된 148개 중 원본 대비 중복 추정 61개.
브랜드 소개 문서에 답변 가능한 형태의 사실 문장이 없음높음진단 코드 GEO-02. 회사·브랜드 소개 6개 페이지 중 5개가 이미지 안에 텍스트를 넣은 형태. HTML 텍스트로 추출 가능한 문장은 평균 3문장. 생성형 AI가 인용할 문단 단위 근거 부족.
AI 크롤러 접근 정책이 정의되지 않음중간진단 코드 CRAWL-01. robots.txt에 GPTBot·Google-Extended 등 AI 크롤러 관련 지시문 없음(기본 템플릿 그대로). llms.txt 부재. 서버 로그 표본 7일 기준 AI 계열 UA 접근 시도 확인됨.
제품 이미지·스크립트 미최적화로 모바일 렌더링 지연중간진단 코드 PERF-02. 모바일 LCP 표본 측정 4.8초(주요 랜딩 5개 평균). 상품 목록 첫 화면에 원본 크기 이미지 12장 즉시 로드. 미사용 스크립트 3종 전역 로드.
