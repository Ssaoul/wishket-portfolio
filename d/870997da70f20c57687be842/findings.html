제품 상세 페이지에 구조화 데이터(Product/Organization) 없음 높음

근거 — 진단 코드 SD-01. 수집한 제품 페이지 148개 중 JSON-LD 스키마 출력 0개. 고도몰 기본 스킨의 goods_view 템플릿이 메타 태그만 출력하고 schema.org 마크업을 포함하지 않음.

조치 — goods_view 템플릿에 Product·Offer·Organization JSON-LD 블록 삽입. 상품 DB 필드(모델명·규격·인증번호)를 직접 바인딩해 수기 입력 없이 자동 출력.

동일 상품이 파라미터 URL 4종으로 중복 색인 높음

근거 — 진단 코드 IDX-03. 대표 상품 1건에 ?cate=/?page=/?sort=/? 조합으로 서로 다른 URL 4개가 색인. canonical 태그 미선언. 색인된 148개 중 원본 대비 중복 추정 61개.

조치 — canonical 자동 생성 규칙 적용, 파라미터 조합은 robots 및 canonical로 원본에 통합. 통합 후 색인 감소는 정상 동작이므로 리포트에 사전 고지.

브랜드 소개 문서에 답변 가능한 형태의 사실 문장이 없음 높음

근거 — 진단 코드 GEO-02. 회사·브랜드 소개 6개 페이지 중 5개가 이미지 안에 텍스트를 넣은 형태. HTML 텍스트로 추출 가능한 문장은 평균 3문장. 생성형 AI가 인용할 문단 단위 근거 부족.

조치 — 소개·제품 설명을 HTML 텍스트로 재구성하고 FAQ 블록(질문-답변 쌍)을 추가. 이미지에는 대체 텍스트를 부여하되, 사실 정보는 텍스트 본문에 중복 배치.

AI 크롤러 접근 정책이 정의되지 않음 중간

근거 — 진단 코드 CRAWL-01. robots.txt에 GPTBot·Google-Extended 등 AI 크롤러 관련 지시문 없음(기본 템플릿 그대로). llms.txt 부재. 서버 로그 표본 7일 기준 AI 계열 UA 접근 시도 확인됨.

조치 — 공개 허용 범위를 발주처와 협의해 robots.txt 및 llms.txt에 명시. 비공개로 남길 경로(견적·회원 영역)는 명시적으로 차단.

제품 이미지·스크립트 미최적화로 모바일 렌더링 지연 중간

근거 — 진단 코드 PERF-02. 모바일 LCP 표본 측정 4.8초(주요 랜딩 5개 평균). 상품 목록 첫 화면에 원본 크기 이미지 12장 즉시 로드. 미사용 스크립트 3종 전역 로드.

조치 — 목록/상세 이미지 지연 로딩 및 WebP 변환, 전역 스크립트를 필요한 페이지로 한정. 고도몰 스킨 캐시 정책과 충돌 여부를 스테이징에서 선검증.

사이트맵이 오래된 상태로 고정 — 신규·단종 상품 미반영 중간

근거 — 진단 코드 IDX-07. sitemap.xml 최종 갱신일이 등록일 기준 과거 시점에 멈춰 있음. 사이트맵에 없는 신규 상품 페이지 23개, 사이트맵에만 남은 단종 상품 9개(접속 시 404).

조치 — 상품 DB 기준 사이트맵 자동 생성 배치 구성. 단종 상품은 410 또는 후속 상품으로 301 처리 방침을 발주처와 확정.

브랜드 사이트 간 정보 불일치 — AI 답변 시 근거 충돌 중간

근거 — 진단 코드 GEO-05. 공식 홈페이지와 브랜드 사이트 2곳에서 회사 설립 연도·주소 표기가 서로 다름(3곳 중 2곳 불일치). 동일 제품의 규격 표기 단위도 사이트별 상이.

조치 — 기업 기본 정보를 단일 원천으로 정의하고 각 사이트 Organization 스키마에 동일 값 주입. 확대 적용 시 공통 항목으로 우선 처리.

검색 성과 측정 도구가 연결되어 있지 않음 낮음

근거 — 진단 코드 MEA-01. Search Console 속성 미등록(소유권 확인 이력 없음). 분석 도구는 설치되어 있으나 유입 채널 구분 설정 없음 — 생성형 AI 경유 유입이 direct로 합산됨.

조치 — Search Console 속성 등록 후 기준선 확보. AI 서비스 referrer를 별도 채널 그룹으로 분리하고, 참조자가 비는 경우를 대비해 랜딩 URL 파라미터 규칙을 병행.
