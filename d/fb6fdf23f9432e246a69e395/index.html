한 번 요청, 여러 견적

같은 사양을 업체마다 다시 설명하고, 받은 견적은 양식이 제각각이라 비교가 안 됩니다. 요청 한 건에 업체별 견적을 같은 항목으로 세워 놓고, 관리자가 승인·반려까지 한 화면에서 처리합니다.

이용 흐름

사용자가 하는 일이 끊기지 않는다

1. 회원 유형 선택·가입
병원은 사업자등록번호·요양기관기호를, 개원 준비는 의사면허번호·전문과목·개원 예정 지역을 입력한다 (외부 인증 연동 없이 정보 수집)
2. 견적 요청 작성
장비 종류·진료과·구매 목적·지역·도입 시기를 넣고, 초음파를 고르면 사용 목적과 프로브 문항이 이어서 열린다
3. 요청 공개 · 업체 제안
관리자 확인 후 요청이 공급업체 목록에 뜨고, 조건에 맞는 업체가 알림을 받아 견적을 제출한다
4. 견적 비교 · 문의
업체별 견적을 본체가·프로브 구성·설치비·보증기간 같은 같은 항목으로 나란히 보고, 궁금한 곳에 문의를 남긴다
5. 업체 선택 · 플랫폼 밖 진행
비교 후 연결을 요청하면 담당자 정보가 공개된다. 계약과 대금은 병원·업체 당사자끼리 직접 진행한다 (플랫폼 결제 없음)
