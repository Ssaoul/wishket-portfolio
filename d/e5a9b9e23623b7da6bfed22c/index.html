제공 항목

Primary / Brand-600

로고 주색과 조화되는 기준 색. CTA 버튼·활성 탭·링크에만 사용하며 본문 배경에는 쓰지 않는다.

Surface / Level 0~2

페이지 배경·카드·팝오버 3단계 표면 색. 단계 간 명도 차 4% 이상으로 테두리 없이도 층이 읽힌다.

State / Error·Warning·Success

반려·품절·검수 완료 등 거래 상태 뱃지용. 색만으로 구분하지 않도록 아이콘·텍스트를 항상 병기한다.

Heading 1~3 / Pretendard

32·24·20px, 굵기 700·600·600. 섹션 제목과 카드 제목의 위계를 크기와 굵기 두 축으로 분리.

Body / Caption

본문 16px 400, 보조 14px 400, 캡션 12px 500. 캡션은 작아지는 대신 굵기를 올려 가독성을 보전.

8px 간격 스케일

4·8·12·16·24·32·48·64 토큰. 섹션 사이 64, 카드 사이 24, 카드 내부 16을 기준값으로 고정.
