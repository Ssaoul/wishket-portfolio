Page-Order Builder for School Print Orders

쪽 순서로 받는 첫 문의

말로 온 문의를 직원이 쪽 목록으로 다시 옮기고, 빠진 쪽을 되묻는 일이 반복됩니다. 선생님이 직접 짠 구성표를 먼저 서버에 저장해 번호를 발급하고, 메일 발송에 실패해도 접수 건은 남게 했습니다. 사내 시스템은 이 구성표를 API로 가져가 초벌 작업에 씁니다.

3단 정렬
인기 등급 → 조회수 → 최신순
20MB·30개
파일당 크기 · 1회 첨부 상한
4중 거름
캡차·숨은 칸·과속·반복 제출
API 1종
번호 + 서버 키로만 열람

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.

이용 흐름

사용자가 하는 일이 끊기지 않는다

부품 고르기
품목을 정하고 표지·간지·내지 탭에서 샘플을 골라 쪽 순서대로 담는다. 고르던 내용은 브라우저에 자동 저장된다.
미리보기·표시
양면·한 쪽 넘김으로 책 모양을 확인하고, 펜·글상자로 고칠 곳을 표시한다. 바꿀 쪽에는 내 원고 파일을 붙인다.
보내기 입력
문의 내용, 기관명·담당자·연락처, 수량·받을 날을 적고 개인정보 동의 후 캡차를 통과한다.
번호 발급
서버 저장이 끝나면 구성표 번호가 화면에 뜬다. 메일은 그다음 발송되며, 실패해도 접수 건은 남는다.
관리자 처리
직원이 관리 목록에서 구성표를 열어 쪽 순서·표시·첨부를 확인하고, 사내 시스템은 API로 같은 구성표를 가져간다.
