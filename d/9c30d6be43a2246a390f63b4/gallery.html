어드민 업로드
사진 12장 한 번에 끌어놓기
운영자가 구조 현장 사진 12장을 드래그로 올림. 원본 중 3장이 기준 용량 초과 → 업로드 시점에 자동 리사이즈·WebP 변환, 썸네일 별도 생성. 1장은 손상 파일로 판정돼 '다시 올려주세요' 안내.
트래픽 대응
구조 영상 확산으로 방문 급증
구조 소식이 메신저 채널로 공유되며 개체 상세 페이지 조회가 짧은 시간에 몰린 상황을 가정. 이미지는 CDN 캐시에서 응답하고 원본 서버는 HTML만 처리하는 구성으로 다운 없이 버티는 흐름을 시연.
보안·권한
비공개 글 URL 직접 접근
학대 의심 사건 개체의 상세 URL을 외부에서 직접 입력. 링크 숨김이 아니라 서버가 권한을 확인해 접근 거부 화면을 반환하고, 관리자 로그에 접근 시도 기록.
데이터 이전
기존 URL 301 매핑 누락
시험 이전 단계에서 옛 게시판 주소 일부가 매핑표에 빠져 404 발생. 누락 목록이 이전 내역서에 자동 집계되어 전체 이전 전에 보완 후 재검증.
외부 연동
봉사 신청 폼 시트 전송 실패
이동봉사 신청이 스프레드시트로 전송되던 중 연동 오류 발생. 신청자에게는 정상 접수 안내, 신청 데이터는 재시도 대기열에 보관 후 자동 재전송.
다국어
영문 변환 용어집 미등록 단어
영문 버튼 전환 시 '임시보호', '이동봉사'가 용어집에 없어 직역으로 표시됨. 관리자 화면에 미등록 용어 목록이 떠서 운영진이 바로 번역어를 등록.

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
