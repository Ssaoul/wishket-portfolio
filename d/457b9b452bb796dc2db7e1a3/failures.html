E_NOT_MEMBERQR·번호가 명단에 없음. 주 1회 업로드 특성상 갓 가입한 기사는 다음 배치 전까지 조회되지 않음정상가로 결제 진행하되 화면에 '회원 확인이 안 됩니다 — 카운터에 문의' 안내. 실패 로그에 입력 뒷자리를 남겨 다음 배치 검수 목록으로 올림
E_AUTH_EXPIRED인증 후 메뉴를 고르다 TTL 180초 초과. 결제 단계에서 회원가가 유효하지 않음orders/confirm에서 409로 차단하고 재인증 화면으로 복귀. 담긴 장바구니는 유지해 처음부터 다시 고르게 하지 않음
E_DUP_REQUEST네트워크 지연으로 키오스크가 같은 인증·주문을 재전송. 그대로 두면 할인이 두 번 잡힘idempotencyKey로 24시간 내 동일 요청 판별 → 새로 처리하지 않고 최초 응답을 그대로 반환(200). 응답에 replayed:true 표기
E_PAY_TIMEOUT결제 승인 응답이 오지 않아 인증은 소진됐는데 결제 성사 여부가 불명확주문을 PENDING으로 잠그고 30초 간격 3회 조회(지수 백오프). 끝내 불명이면 인증을 복원하지 않고 관리자 확인 대기 큐로 이동 — 조용한 이중 할인보다 사람 확인이 안전
E_IMPORT_SCHEMA엑셀 열 이름이 바뀌거나 번호 자릿수·중복이 섞임(예: 010-1234-56789, 같은 번호 2행)DRY_RUN에서 전량 차단. 정상 행만 미리보기로 보여주고 오류 행은 행번호·원본값과 함께 반환. commitToken 없이는 실제 반영되지 않음
