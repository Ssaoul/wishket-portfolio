되돌리기 어려운 작업은 세 가지입니다 — 실서비스 도메인 전환(DNS), 기존 회원·주문 데이터 이관, 기존 서버 정리. 전환은 기존 사이트를 끄지 않은 채 신규를 별도 도메인에서 검수한 뒤 DNS만 바꾸는 방식으로 진행하고, 문제가 보이면 DNS를 되돌려 기존 사이트로 즉시 복귀합니다. 데이터는 이관 직전 스냅샷과 이관 후 건수 대조표를 남기고, 기존 서버와 소스는 침해 흔적 조사 근거이자 롤백 대비로 전환 후 최소 30일간 외부 접근을 끊은 상태로 보관합니다.
