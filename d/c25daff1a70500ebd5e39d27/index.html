지점·룸 선택
지점 카드에서 지점을 고르고 룸 목록에서 용도·기본 인원을 확인해 선택한다
날짜·시간 슬롯 선택
캘린더에서 날짜를 고르고 잔여 시간 슬롯을 다중 선택한다. 선택 즉시 슬롯이 잠기고, 이미 잠긴 슬롯은 회색으로 막힌다
인원·예약자 정보 입력
인원을 넣으면 초과 인원 요금이 실시간 합산된다. 회원 로그인 또는 비회원 정보 입력 중 선택한다
결제
신용카드 또는 무통장 입금을 고른다. 카드 승인 시 호스트 승인 없이 즉시 확정된다
확정·출입 안내 수신
완료 페이지에서 예약번호·결제금액을 확인하고, 알림톡(실패 시 SMS)으로 지점별 출입 정보를 받는다
