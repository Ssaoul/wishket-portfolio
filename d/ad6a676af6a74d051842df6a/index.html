평면도 한 장에서 시공 상담까지

사내 프론트 코드에 AI 모듈 3종을 붙이는 일은 화면이 아니라 응답 지연과 실패 처리에서 일정이 밀립니다. 체험을 마친 고객이 상담 신청을 남기고 관리자가 그 DB를 바로 꺼내 쓰는 한 바퀴를 먼저 완결했습니다.

이용 흐름

사용자가 하는 일이 끊기지 않는다

단지·동·호수 검색
지역과 단지명으로 검색해 동·호수를 고르면 평면도를 불러온다. 평면도가 없으면 도면 업로드 안내로 분기한다.
평면도에서 방 선택
평면도 위에서 시공할 거실·침실을 터치로 선택한다. 선택값은 API 요청 본문으로 조립된다.
AI 견적 결과 확인
자동설계 API 호출 중 로딩 화면을 띄우고, 8초 초과나 오류 응답이면 재시도 버튼과 수동 견적 안내를 보여준다.
시공 상담 신청
이름·연락처·희망 일정·현장 사진을 입력해 제출한다. 견적 결과 ID가 함께 저장돼 관리자가 맥락을 본다.
마이페이지에서 내역 확인
내 견적/상담 내역에서 접수번호·상태·견적 범위를 조회한다. 처리 상태는 관리자 변경 즉시 반영된다.
