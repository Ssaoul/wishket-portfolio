사진 12장 끌어놓기 업로드
운영자가 휴대폰 원본 사진 12장을 한꺼번에 끌어다 놓은 경우입니다. 업로드할 때 목록용·상세용·원본 보관용 세 가지 크기로 나눠 저장하고, 공개 화면은 지연 로딩으로 필요한 크기만 불러옵니다.
실패·예외
25MB 단일 이미지 업로드
업로드 상한을 넘은 파일은 저장하지 않고 거절합니다. '사진 용량이 커서 올리지 못했습니다. 자동으로 줄여서 다시 올릴까요?'라는 안내를 쉬운 말로 보여주고, 코드나 FTP 화면은 나오지 않습니다.
실패·예외
비공개 공지 주소 직접 접근
숨김 처리한 공지의 주소를 알고 들어오는 경우입니다. 비로그인 요청은 서버가 페이지를 내려주지 않고 403 안내 화면으로 보냅니다. 링크를 감추는 대신 요청 단계에서 권한을 확인합니다.
부하 대응
구조 소식 확산으로 방문 급증
구조 영상이 공유되어 같은 소식 페이지에 접속이 몰리는 시나리오입니다. 정적 페이지와 이미지는 CDN 캐시에서 응답하고, 원 서버는 관리자 쓰기 요청만 받는 구조를 가정했습니다.
실패·예외
기존 게시판 URL 301 매핑 누락 3건
시험 이전 단계에서 기존 게시판 주소 중 매핑표에 없는 3건이 404로 확인된 경우입니다. 이전 내역서에 '미매핑'으로 표시하고, 운영진이 확인해 승인한 뒤에 전체 이전으로 넘어갑니다.
실패·예외
봉사 신청 폼 스프레드시트 연동 실패
연동 권한이 만료되어 스프레드시트에 기록하지 못한 경우입니다. 신청 내용은 사이트에 먼저 저장하고, 관리자 화면에 '연동 대기 1건'을 띄워 다시 보내기 버튼으로 처리합니다.

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
