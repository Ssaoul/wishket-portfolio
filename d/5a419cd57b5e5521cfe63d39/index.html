처리 단계

입력에서 산출물까지 어디를 지나는가

응답 수집
개인정보 수집·이용 동의 확인 후 28문항 선택형 응답을 세션 단위로 저장한다. 중도 이탈 시 마지막 문항 번호까지 보존한다.
응답 검증
필수 문항 누락·중복 제출·동의 미체크를 걸러낸다. 결측이 3문항 이하면 보정 규칙으로 통과, 초과하면 분류로 넘기지 않는다.
지표 산출
응답을 활동강도·규칙성·사교성·회복선호 4개 축 점수로 환산한다. LLM 호출 전 결정적 계산으로 처리해 같은 응답은 항상 같은 축 점수를 낸다.
유형 분류
축 점수와 응답 요약을 외부 LLM API에 보내 8개 유형 중 하나로 분류하고 근거 문장을 받는다. 정의된 유형 코드 밖 응답은 무효 처리한다.
결과카드 생성
유형명·성향 지표 막대·추천 스포츠·추천 콘텐츠 문구를 세로형(1080×1920) 카드 이미지로 렌더한다. 공유 링크와 함께 발급한다.
원본 적재
문항별 원본 응답·축 점수·유형·카드 URL을 DB에 적재하고 관리자 화면의 CSV 내보내기 대상에 포함한다.
