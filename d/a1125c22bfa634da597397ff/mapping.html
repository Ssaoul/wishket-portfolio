AI API 요청 body.promptmessage.text앞뒤 공백 제거, 1,000자 초과 시 전송 전 입력창에서 차단하고 글자수 안내
AI API 요청 body.context[]history 최근 6턴세션 내 최근 대화만 잘라 전달, 개인정보 패턴(전화·이메일)은 마스킹 후 전송
AI API 요청 header.X-Request-IdclientMsgId프론트가 생성한 질문 ID를 그대로 전달해 서버·AI 로그를 한 줄로 추적
AI API 응답 output.textmessage.answerHTML 태그 이스케이프 후 줄바꿈·목록만 허용된 마크다운으로 렌더
AI API 응답 output.sources[]message.links자사 도메인 경로만 허용, 외부 URL은 표시하지 않음
AI API 응답 finish_reasonmessage.statusstop→answered, length→answered(잘림 표시), filtered→blocked, 그 외→failed
AI API 응답 usage.total_tokenslog.tokens화면에 노출하지 않고 서버 로그에만 기록 (호출량 점검용)
HTTP statusmessage.errorCode408·504→CHAT_TIMEOUT, 429→CHAT_RATE_LIMIT, 5xx→CHAT_UPSTREAM, 401·403→CHAT_AUTH
