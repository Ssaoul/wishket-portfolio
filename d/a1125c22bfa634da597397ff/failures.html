실패 처리

연동은 실패를 어떻게 다루느냐로 갈린다

코드원인처리
CHAT_TIMEOUTAI API 응답이 20초 안에 오지 않음'답변을 준비 중입니다' 표시 유지 후 상태 조회 API로 폴링, 최종 실패 시 [다시 묻기] 버튼 노출. 같은 clientMsgId로 재요청해 답변 중복 방지
CHAT_DUPLICATE전송 버튼 연타·엔터 중복으로 같은 질문이 두 번 도착Idempotency-Key 일치 시 AI 재호출 없이 첫 번째 결과를 그대로 반환, 말풍선도 하나만 표시
CHAT_RATE_LIMITAI API 호출 한도 초과(429)Retry-After 값만큼 대기 후 최대 2회 자동 재시도(1초→3초), 그래도 실패하면 '잠시 후 다시 시도해 주세요' 안내
CHAT_UPSTREAMAI API 5xx 오류 또는 빈 응답(output.text 없음)빈 답변을 화면에 그리지 않고 오류 말풍선으로 대체, 입력창은 계속 사용 가능하게 유지
CHAT_SESSION_EXPIRED30분 이상 유휴로 세션 만료새 세션을 조용히 재발급하고 마지막 질문만 자동 재전송, 이전 대화는 '이전 대화' 구분선 아래 유지
CHAT_AUTH서버 측 AI API 키 만료·권한 오류(401/403)사용자에게는 일반 오류 문구만 표시, 운영자에게 즉시 알림. 재시도해도 소용없는 오류라 자동 재시도 대상에서 제외

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
