BLDC Type Hybrid Magnet Boiler

시제품 단계. 특허 출원 중이며 내구성·신뢰성·제연성 시험 진행 중. 화면에는 '개발 중' 상태 배지로 표기.

BLDC Type Motor

시제품 제작 완료, 제품 인증 절차 진행 중. 성능 수치는 시험 성적서 수령 후 반영.

7축 갠트리 용접 로봇

장비 목록 페이지에 사진과 함께 게시. 장비별 규격표는 발주처 제공 자료 기준으로 채웁니다.
