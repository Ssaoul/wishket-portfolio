외부 필드내부 필드변환 규칙
성명 (엑셀 A열)member.name앞뒤 공백 제거, 화면에는 가운데 글자 마스킹(김*수)으로만 노출
휴대폰번호 (엑셀 B열)member.phoneHash / phoneTail하이픈·공백 제거 후 11자리 검증 → 전체는 해시 저장, 뒷 4자리만 조회용으로 별도 보관
QR 스캔값auth.memberNo`MP:<회원번호>:<검증코드6자리>` 형식 파싱, 검증코드 불일치 시 즉시 거절
키오스크 장바구니 menuCodepricing.menuCode포스 메뉴코드와 1:1 매핑표 유지, 미등록 코드는 할인 미적용·정상가 처리
결제 승인번호payment.approvalNo문자열로 보존(선행 0 유실 방지), 일자+단말ID와 묶어 유일성 확인
단말 구분 (대형/소형)device.profileKIOSK=카메라 인증 우선, POS=번호 입력 우선. 계약은 동일, 기본 진입 화면만 분기
회원 적용 단가pricing.memberPrice할인율이 아닌 회원 전용 고정단가 테이블 참조(반올림 오차 제거)
업로드 시각import.effectiveFrom업로드 완료 시각 기준 즉시 반영, 이전 배치는 이력으로 보존해 되돌리기 가능
