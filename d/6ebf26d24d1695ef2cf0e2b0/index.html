MemberPass — Kiosk Plugin Integration Layer for Member Pricing

무인 키오스크 결제 흐름에 회원 인증을 끼워 넣을 때, 요청/응답 계약과 실패·중복·재시도를 먼저 못박은 연동 설계 데모

키오스크 플러그인은 우리 서버가 아니라 매장 단말 위에서 돕니다. 네트워크가 끊기거나 손님이 인증 버튼을 두 번 눌러도 할인이 두 번 적용되면 안 되고, 인증은 성공했는데 결제가 취소된 세션은 반드시 되돌아와야 합니다. 이 데모는 그 경계에서 오가는 계약(요청/응답)과 실패 처리 규칙을 화면으로 보여줍니다.

6종연동 엔드포인트
3단계인증→가격→결제확정
5종정의된 실패 코드
24시간멱등키 보존 구간

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.

연동 구성

무엇과 무엇이 어떤 순서로 오가는가

1. POST /v1/auth/qrQR 스캔값으로 회원 인증세션 발급
2. POST /v1/auth/phone휴대폰 번호 뒷자리 입력 대안 인증(QR 미소지 시)
3. POST /v1/pricing/quote장바구니에 회원가/정상가 중 하나를 확정 산출
4. POST /v1/payments/confirm단말 결제 완료 후 인증·금액·거래를 한 건으로 확정(멱등)

단말은 매장별로 발급한 디바이스 키로 서버와 상호 인증하고, 인증세션 토큰은 180초 뒤 자동 만료돼 손님이 자리를 떠난 뒤 남은 화면으로 남의 할인이 붙는 일을 막습니다. 회원 개인정보는 단말로 내려보내지 않고 마스킹된 이름·번호만 회신하며, 원본 번호는 해시로만 대조합니다. 결제 확정은 '단말 식별자 + 단말 거래번호' 조합의 멱등키로 24시간 잠그기 때문에, 통신 지연으로 같은 요청이 몇 번 들어와도 영수증은 하나이고 할인도 한 번만 적용됩니다.
