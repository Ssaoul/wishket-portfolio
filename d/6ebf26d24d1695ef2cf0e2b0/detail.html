·
인증 시점
메뉴 선택 전(기본) / 결제 직전(대안) — 매장 설정으로 전환
·
할인 적용
품목별 회원가 테이블 참조, 할인 불가 품목은 정상가 고정
·

엑셀·시트 업로드 → 검증 리포트 확인 → 승인 시 반영(주 1회 기준)
·
결제 정보 전송

·
실패 처리
인증 3회 실패 시 정상가 주문으로 자동 전환 + 안내 문구
·
단말 대응
대형 키오스크(세로) · 소형 포스(가로) 레이아웃 분기

신청 절차

1. 회원 확인
화면에서 '기사 회원' 또는 '일반 손님'을 고른다. 일반 손님은 바로 메뉴로 넘어간다.
2. 인증
발급받은 QR을 스캐너에 대거나, QR이 없으면 휴대폰 뒷4자리를 누른다.
3. 결과 확인
'회원 확인됨 · 김OO 님' 또는 '명단에 없습니다'가 즉시 뜬다. 실패해도 주문은 계속할 수 있다.
4. 메뉴 선택
인증되면 회원가가 표시된 메뉴판이, 아니면 정상가 메뉴판이 뜬다. 할인 불가 품목은 같은 값으로 표시된다.
5. 결제
적용 단가와 할인액을 마지막으로 보여주고 결제 단말로 넘긴다. 영수증에 회원 적용 여부가 찍힌다.

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
