실패 처리

연동은 실패를 어떻게 다루느냐로 갈린다

코드원인처리
AUTH_NOT_FOUND스캔·입력한 회원이 명단에 없음(신규 기사, 아직 미등록)화면에 '회원 확인 불가 — 정상가로 진행' 안내 후 결제는 그대로 진행. 미인증 시도로 기록해 운영자 리포트에 남김
AUTH_AMBIGUOUS휴대폰 뒷 4자리가 2명 이상과 일치성(姓) 한 글자 추가 입력 화면으로 전환. 그래도 좁혀지지 않으면 QR 인증 안내
QR_INVALID_SIGNATURE캡처·재사용된 QR이거나 검증코드 불일치거절하고 재스캔 유도. 동일 단말에서 3회 연속 실패 시 번호 입력 경로로 자동 전환
QUOTE_EXPIRED금액 산출 후 3분이 지나 단가가 만료됨(손님이 화면 앞에서 지체)결제 직전 재산출 후 변경된 금액을 확인 화면에 표시. 사용자 동의 없이 금액을 바꾸지 않음
UPSTREAM_TIMEOUT결제 승인은 났는데 확정 기록 응답이 유실됨단말이 동일 멱등키로 재전송. 서버는 기존 결과를 replayed:true 로 되돌려주고 이중 기록하지 않음
IMPORT_ROW_REJECTED업로드 행의 번호 형식 오류·중복 번호·빈 성명해당 행만 거절하고 나머지는 반영. 거절 사유가 붙은 리포트를 내려 담당자가 시트에서 그 줄만 고치게 함

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
