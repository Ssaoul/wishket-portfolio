실패 처리

연동은 실패를 어떻게 다루느냐로 갈린다

코드원인처리
AUTH_NOT_FOUNDQR·번호가 회원 명단에 없음(비회원 또는 미반영 신규 가입)인증 실패 안내 후 정상가 흐름으로 계속 진행 — 결제를 막지 않는다. 실패 로그에 시도값 해시만 기록
AUTH_SESSION_EXPIRED인증 후 180초 내 결제 미완료(손님이 메뉴 고르다 이탈)가격 산출 단계에서 만료 감지 → 재인증 유도 화면. 만료 세션의 quote 는 자동 폐기
DUPLICATE_CONFIRM통신 지연으로 단말이 확정 요청을 재전송, 혹은 손님이 버튼 연타멱등키로 기존 영수증 조회해 동일 응답 반환(duplicated:true). 할인은 두 번 적용되지 않음
AMOUNT_MISMATCH단말이 보낸 결제 금액과 서버 산출 회원가가 다름(정책 변경 중 결제 등)확정 거부 후 단말에 재산출 요청. 관리자 알림 발송, 해당 거래는 미확정 큐에 보관
UPSTREAM_TIMEOUT매장 네트워크 불안정으로 인증 응답 3초 초과지수 백오프 2회 재시도(0.5s→1.5s) 후에도 실패 시 정상가 폴백. 인증 성공분은 단말 로컬 큐에 적재해 복구 시 재동기화
IMPORT_ROW_INVALID업로드 시트에 번호 형식 오류·중복 행 존재(412행 중 7행)전체 반려 대신 유효 행만 반영, 실패 행은 사유가 붙은 스킵 리포트로 관리자에게 회신

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
