제공 항목

메인 페이지 (TPL-01)

국내 사이트와 같은 순서로 히어로·솔루션·포트폴리오·뉴스를 배치합니다. 히어로 문구와 배너 이미지는 관리자가 블록 편집기에서 바로 바꿀 수 있습니다.

About Us · 연혁 (TPL-02)

연도별 연혁을 반복 입력 필드로 만들어서, 한 줄을 추가해도 코드 수정이 필요 없습니다. 모바일에서는 세로 타임라인으로 바뀝니다.

솔루션 상세 (TPL-05)

제품마다 같은 틀(개요·사양표·적용 분야·문의 버튼)을 씁니다. 사양표는 모바일에서 가로 스크롤로 처리해 숫자가 잘리지 않게 했습니다.

솔루션 목록 (TPL-04)

분류 필터와 카드형 목록입니다. 새 제품을 등록하면 목록에 자동으로 추가되고, 노출 순서는 관리자가 드래그로 정합니다.

포트폴리오 아카이브 (TPL-07)

기존 글로벌 사이트의 포트폴리오 글을 그대로 옮겨옵니다. 국가·산업·연도 태그로 거르고, 기존 글 주소는 유지하거나 301로 연결합니다.

포트폴리오 상세 (TPL-08)

사진 갤러리, 프로젝트 개요, 관련 솔루션 링크로 구성됩니다. 관리자는 사진과 본문만 넣으면 되고, 레이아웃은 고정입니다.
