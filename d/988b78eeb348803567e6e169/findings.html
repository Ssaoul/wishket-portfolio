발견 항목

무엇이 병목인지와 그 근거

영문 페이지에 hreflang·캐노니컬 미설정 높음

근거 — 점검 대상 42개 URL 중 영문 28개 전부에 hreflang 없음, 캐노니컬은 국문 URL로 고정 출력(28/28)

조치 — 국문·영문 상호 hreflang 쌍 삽입, 캐노니컬을 현재 언어 URL로 동적 출력하도록 공통 헤드 파일 1곳 수정

제품 상세 8개 화면에 구조화 데이터 없음 높음

근거 — 제품 상세 8개 화면 JSON-LD 0건. 검색 결과에 제품명·성분 정보가 텍스트로만 노출

조치 — Product·Organization·BreadcrumbList JSON-LD를 언어별로 분리 삽입. 효능 단정 표현은 넣지 않고 제품 사양 항목만 마크업

메타 설명이 전 페이지 동일 문구로 복제 중간

근거 — 42개 URL 중 37개가 동일한 description 1줄을 공유. 영문 5개는 태그 자체가 비어 있음

조치 — 페이지 유형별 템플릿 변수화(제품명·카테고리 치환), 담당자가 관리자 화면에서 직접 수정 가능한 입력란 추가

이전 배너 이미지 경로 깨짐 및 대체 텍스트 누락 중간

근거 — 메인·서브 배너 이미지 14개 중 3개가 404, alt 속성 누락 11개

조치 — 깨진 경로 3건 교체, 배너 등록 시 alt 입력을 필수값으로 변경

모바일 화면에서 제품 표 가로 넘침 중간

근거 — 폭 390px 환경에서 제품 상세 8개 중 5개 화면의 성분표가 화면 밖으로 넘침

조치 — 표를 가로 스크롤 영역으로 감싸고 최소 폭 지정. 원본 마크업은 유지

robots.txt·사이트맵이 영문 경로를 제외 중간

근거 — sitemap.xml에 국문 14개 URL만 등재, 영문 28개 URL 미등재. robots.txt 최종 수정 2024년

조치 — 언어별 사이트맵 분리 생성 후 인덱스 사이트맵으로 묶고, 검색엔진 도구에 재제출

요청 접수 이력이 남지 않아 지연 원인 추적 불가 낮음

근거 — 인계 문서 7차분에서 접수일·회신일이 적힌 건 0건. 반영 여부는 담당자 기억에 의존

조치 — 수정요청번호 부여 규칙(REQ-연월-일련)과 상태 5단계를 정하고, 접수 회신을 24시간 내 문서로 남김

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
