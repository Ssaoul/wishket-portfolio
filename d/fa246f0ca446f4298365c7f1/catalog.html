회사 소개사업 분야소식문의관리자 편집
이름분류설명
회사 소개 (인사말·비전)회사 소개대표 인사말과 비전을 한 화면으로 통합. 기존 '회사 소개 / CEO 인사말 / 비전' 3페이지를 1페이지로 축소. 본문 텍스트는 관리자 화면에서 담당자가 직접 수정.
회사 연혁회사 소개연도별 항목을 관리자 화면에서 추가·수정·삭제. 연도·월·내용 3칸만 입력하면 타임라인에 자동 반영. 개발자 없이 운영 가능한 영역.
사업 분야사업 분야정밀 가공·금형·조립 3개 분야를 카드로 배치. 상세 텍스트와 대표 이미지는 파트너 선정 후 발주처가 제공하는 콘텐츠로 교체 예정(현재는 합성 자리표시).
인증·설비 현황사업 분야보유 인증과 주요 설비를 표로 정리. 표의 행은 담당자가 관리자 화면에서 편집. 레이아웃 변경은 파트너 유지보수 범위.
공지사항소식워드프레스 기본 글 기능을 그대로 사용. 제목·본문·첨부파일 등록이 가능하며 담당자가 가장 자주 쓰는 영역.
고객 문의 폼문의회사명·담당자·연락처·문의 내용 4개 항목. 접수 시 담당자 메일로 발송되고 관리자 화면에도 저장. 스팸 방지 체크 포함.
오시는 길 / 기본 정보회사 소개주소·대표번호·운영시간을 '사이트 기본 정보' 한 곳에서 수정하면 하단 푸터와 오시는 길 페이지에 동시 반영.
관리자 대시보드 (담당자용)관리자 편집비개발자용으로 메뉴를 줄인 관리자 화면. 연혁·공지·기본 정보·문의 내역만 보이고 테마·플러그인 설정은 숨김. 교육 매뉴얼 기준 화면.
호스팅 구성 비교관리자 편집공용 웹호스팅과 클라우드 서버의 월 유지 비용·관리 난이도·백업 방식 비교표. 발주처가 직접 선택할 수 있도록 장단점을 나열.
