D+5 — 1종 전체 초안 확인
먼저 1종만 끝까지 만들어 보여드립니다. 여기서 구조가 확정되면 나머지 1종은 같은 틀로 빠르게 갑니다.
중간 확인
D+9 — 수정 반영본 확인
수정 주간의 중간 지점. 남은 회차로 처리 가능한 범위인지 이 시점에 같이 판단합니다.
예외
기획안 카피가 디자인 분량을 초과
합성 예시 — 소개 문단이 배치 가능한 분량보다 길어 3줄이 잘리는 상황. 임의로 줄이지 않고 '이 문장까지만 들어갑니다'를 표시해 담당자가 직접 고르도록 되돌립니다.
예외
제공 촬영컷 해상도 부족
합성 예시 — 메인 비주얼용 1컷이 가로 1200px이라 확대 시 흐려지는 경우. 재촬영 요청 대신 크롭 축소안과 원본 유지안을 함께 내고, 재촬영이 필요하면 D+2에 알립니다.
예외
확정 후 뒤집힌 방향 변경
합성 예시 — D+5 확정 뒤 톤을 바꾸자는 요청. 2주 안에서는 전면 변경이 어려우므로 '이번에 반영 가능한 범위'와 '다음 건으로 넘길 범위'를 나눠 적어 드립니다.

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
