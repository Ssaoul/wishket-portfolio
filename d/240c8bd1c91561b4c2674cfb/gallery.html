전환 성공
포털 검색 유입 → 상담 신청 완료
첫 화면 핵심 메시지 → 차별점 → 학년별 방향까지 읽고 중간 CTA로 폼 제출. 유입 경로가 검색광고로 기록되어 어떤 광고에서 왔는지 확인됩니다.
전환 이탈
폼 진입했지만 이탈
연락처 입력 단계에서 벗어난 경우. 폼진입 이벤트만 남고 제출 이벤트가 없어 '진입 대비 제출' 구간이 분리 측정됩니다. 항목 수를 줄일 근거가 됩니다.
입력 오류
연락처 형식 오류로 제출 실패
숫자 10자리 미만 입력. 제출 버튼이 막히고 해당 칸 아래 안내가 뜹니다. 실패는 전환으로 집계되지 않습니다.
응대 불가
야간 전화 연결 시도
운영시간 외 전화 버튼을 누른 경우. 통화 대신 '상담 가능 시간 안내 + 폼 남기기'로 유도합니다. 이 경우도 별도 이벤트로 남습니다.
경로 이탈
메신저 채널 연결 후 이탈
외부 메신저 채널로 넘어간 뒤의 행동은 랜딩 측정 범위 밖입니다. 랜딩 쪽에는 '채널 연결 클릭'까지만 기록되며, 이후는 채널 관리자에서 확인해야 합니다.
운영 예외
관리자가 문구를 수정하다 SEO 항목을 비움
섹션 제목을 바꾸면서 Meta Description을 지운 경우. 저장 단계에서 경고를 띄우고, 비워 둔 채 저장하면 관리자 목록에 미입력 표시가 남습니다.

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
