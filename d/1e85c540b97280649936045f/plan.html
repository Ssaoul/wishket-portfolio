운영 DB 스키마 변경과 중복 데이터 정리, 운영 서버 배포는 되돌리기 어려운 작업이라 실행 전 DB 덤프와 현재 배포본을 날짜별로 백업합니다. 배포는 담당자 확인 가능한 시간대에 진행하고, 이상이 있으면 직전 배포본과 DB 덤프로 즉시 복원합니다. SNS 콜백 주소 변경은 기존 값을 기록해 두고 로그인 실패 시 원래 설정으로 되돌립니다.
