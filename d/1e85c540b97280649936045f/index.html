항목심각도근거
BUG-01 고객 정보 수정 후 저장이 반영되지 않음(CRUD)높음수정 API가 PUT 대신 POST 로 호출되어 신규 레코드를 만들고 기존 행은 그대로 남음. 합성 테스트 40건 중 40건 재현, 중복 고객 행 생성 확인.
BUG-02 삭제 버튼이 화면에서만 지워지고 DB 에 남음높음프론트 상태만 갱신하고 DELETE 요청이 전송되지 않음. 새로고침 시 18건 중 18건 복귀.
BUG-03 일반 사용자가 관리자 메뉴 URL 직접 입력으로 진입 가능높음권한 검사가 메뉴 숨김(프론트)에만 있고 Node.js 미들웨어가 비어 있음. 관리자 전용 API 7개 중 7개가 일반 토큰으로 응답.
BUG-04 오픈 SNS 로그인 콜백 후 빈 화면높음운영 도메인의 콜백 주소가 SNS 개발자 콘솔에 미등록이고, 코드에는 로컬 주소가 하드코딩됨. 합성 시도 12건 중 12건 실패.
BUG-05 PostgreSQL 연결 풀 고갈로 간헐적 500 오류중간쿼리 후 커넥션 반환(release) 누락 3곳. 합성 부하 50회 연속 조회 시 21회째부터 응답 없음.
