자격증빙 제출 → 관리자 승인 → 폐쇄 게시판·소모임 탐색 → 참가 신청 → 관리자 처리까지 한 바퀴를 실제로 돌려 본 MVP 시안입니다.

폐쇄형 익명 커뮤니티의 난이도는 게시판 CRUD가 아니라 '누가 어디까지 볼 수 있는가'에 있습니다. 미인증 회원이 목록은 보되 본문·신청은 막히는 권한 게이트, 익명성을 지키면서도 신고·제재를 남기는 처리 기록, 모임 등록이 관리자 중심이라 생기는 운영 부하가 실제 병목입니다. 이 시안은 승인만이 아니라 반려·정원 마감·일정 취소 같은 어긋나는 경로까지 화면으로 보여 줍니다.

4단계자격인증 심사 상태
3중미인증 회원 차단 지점
6종카테고리 게시판(구인구직 포함)
5종관리자 처리 큐

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.

이용 흐름

사용자가 하는 일이 끊기지 않는다

1. 1. 가입 · 프로필 설정이메일 또는 휴대전화로 가입하고 익명 닉네임과 회원 유형을 정합니다. 이 단계에서는 게시판 제목 목록까지만 보입니다.
2. 2. 자격증빙 제출자격 증빙 이미지 또는 PDF를 올립니다. 개인정보 가림 안내가 함께 뜨고, 제출 즉시 상태가 '심사중'으로 바뀝니다.
3. 3. 관리자 심사 (승인 / 반려)관리자가 자료를 확인해 승인하거나 사유를 적어 반려합니다. 반려되면 사유가 마이페이지에 남고 재제출할 수 있습니다.
4. 4. 탐색 · 상세 열람승인된 회원만 게시글 본문·댓글과 모임 상세(장소 포함)를 봅니다. 미인증 상태로 접근하면 인증 안내 화면으로 막힙니다.
5. 5. 참가 신청 · 상태 확인일정에 참가 신청하면 접수번호가 발급되고, 마이페이지에서 신청·대기·취소·마감 상태를 확인하고 취소할 수 있습니다.
