사례

관리자 편집
기존 포스트 복사로 새 글 발행
'계절의 색 · 봄' 포스트를 복사한 뒤 레이아웃은 그대로 두고 대표 이미지·영상·본문만 교체해 '계절의 색 · 여름'으로 발행했습니다. 카테고리와 태그는 복사 시점에 그대로 이어받습니다.
예외 · 저장 차단
컬러 찾기 분기 규칙 누락
1단계 선택지를 6개에서 7개로 늘렸지만 새 선택지 '바다'에 연결된 2단계 질문이 없습니다. 관리자 화면이 '연결되지 않은 선택지 1개'를 표시하고, 이 상태로는 공개 저장이 되지 않습니다.
예외 · 사용자 화면
사전 검색 결과 없음
'코발트'를 검색했지만 등록된 항목이 없습니다. 빈 화면 대신 철자가 비슷한 항목과 같은 분류의 항목을 보여 주고, 관리자에게는 '검색됐지만 결과가 없는 단어' 목록으로 쌓입니다.
예외 · 운영 점검
연관 자료 외부 링크 응답 없음
'이끼색' 항목의 연관 자료 링크 1건이 주간 점검에서 응답하지 않았습니다. 사용자 화면에서는 해당 카드를 숨기고, 관리자 목록에는 '확인 필요'로 표시됩니다.
성능
갤러리 대용량 원본 업로드
8MB 원본 이미지를 '가을' 카테고리에 올리면 웹용 크기로 자동 변환되고 원본은 따로 보관됩니다. 로딩이 빨라야 한다는 요구에 맞춰 목록에는 썸네일만 불러옵니다.
소유권 이전
다른 개발사로 이전 리허설
전체 소스, DB 스키마, 배포·운영 매뉴얼만으로 새 서버에 사이트를 다시 띄우는 절차를 점검하는 시나리오입니다. 특정 업체 계정에 묶인 설정이 남지 않도록 확인합니다.

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
