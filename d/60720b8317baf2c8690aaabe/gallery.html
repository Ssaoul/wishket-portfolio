관리자 · 정상
직원이 새 상품을 사진·글만으로 등록
상품명, 국가, 기간, 대표 사진, 소개글을 입력하고 '공개'를 누르면 국가별 리스트에 바로 나타납니다. 코드를 다룰 일이 없습니다.
관리자 · 정상
상담 링크를 한 곳에서 바꾸면 전 페이지에 반영
설정 화면에서 오픈채팅 링크 하나만 고치면 모든 상품 상세와 하단 고정 버튼의 상담 링크가 함께 바뀝니다. 페이지마다 따로 고칠 필요가 없습니다.
예외 · 링크 오류
오픈채팅 링크 만료 · 상담 버튼 대체 안내
등록된 링크가 만료되거나 잘못 입력되면 관리자 화면에 경고가 뜹니다. 고객 화면에서는 버튼 대신 '상담 연결 준비 중' 안내와 대체 문의 경로를 보여줍니다.
예외 · 입력 오류
사진 용량 초과로 업로드 거부
휴대폰 원본 사진(8MB)을 올리면 '사진이 너무 큽니다' 안내가 뜨고 자동 축소를 제안합니다. 페이지가 느려지는 것을 미리 막습니다.
예외 · 검증
필수 항목 누락 시 공개 차단
대표 사진이나 기간이 비어 있으면 공개 버튼이 꺼지고 빠진 항목을 빨간 글씨로 알려줍니다. 작성 중이던 내용은 임시 저장으로 남습니다.
운영 · 상태 전환
모집 마감 상품은 삭제 대신 '마감' 표시
모집이 끝난 상품은 삭제하지 않고 '이번 기수 마감' 배지로 바꿉니다. 이미 링크를 받은 고객이 빈 페이지를 보지 않게 하기 위해서입니다.

⚠ 이 화면의 모든 값은 합성 데이터입니다. 납품물이 아니라 제안용 시안입니다.
