About

만들고 끝나지 않는 홈페이지

세움파트너스는 기업 소개 웹사이트와 이를 운영할 관리자 페이지를 함께 만듭니다. 공지사항과 블로그, 접속 팝업까지 담당자가 개발자 도움 없이 직접 등록하고 수정할 수 있도록 관리 화면을 먼저 설계합니다. React와 Next.js, TypeScript, PostgreSQL로 구현하고 서버 구성과 배포까지 마친 뒤 소스 코드와 관리자 계정을 함께 넘겨드립니다.

Process

진행 단계

1주차
제공된 와이어프레임 검토, 화면 목록과 데이터 구조 확정
2주차
사용자 페이지 퍼블리싱 — 소개·공지·블로그·팝업 화면 구현
3주차
관리자 페이지 개발 — 글 작성·수정·삭제, 팝업 등록과 노출 제어
4주차
서버·데이터베이스 구성, 배포 후 관리자 계정 전달과 사용 안내
