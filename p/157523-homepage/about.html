About

보유하신 로직을, 쓸 수 있는 서비스로

이미 만들어 두신 프로토타입과 AI 신뢰도 로직 위에 커뮤니티의 기본기를 얹습니다. 로그인, 게시글, 댓글처럼 매일 쓰이는 기능을 먼저 안정적으로 완성하고, 보유하신 검증 로직과 위치 인증은 새로 만들지 않고 연동에 집중합니다. 정해진 예산 안에서 무엇을 먼저 할지 함께 정하고, 남은 범위는 월 단위 유지보수로 이어갑니다.

Process

진행 단계

1주차
프로토타입 분석 · 화면 정의 · API 명세 확정, 신뢰도 API 규격 확인
2주차
회원가입·로그인·세션 관리, 서버·DB·인프라 구성
3주차
게시글 작성·목록(무한 스크롤)·댓글, 이미지 업로드
4주차
신뢰도 점수 API 연동 및 점수 표시 UI, 위치 인증 연동
5주차
통합 테스트 · 스토어 등록 지원 · 소스코드와 기술 문서 인계
