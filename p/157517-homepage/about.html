About

현장에서 읽히는 화면을 만듭니다

온세이프는 식품 제조공장의 모니터링 화면을 다시 설계하는 팀입니다. 기존에 동작하는 시스템을 그대로 두고 화면과 사용 흐름만 바꾸는 방식으로 작업합니다. 장갑을 낀 손, 밝은 조명, 익숙하지 않은 언어 같은 현장 조건을 화면 설계의 조건으로 놓습니다.

Process

진행 단계

1단계
기존 웹 MVP 코드와 기능 명세를 읽고 화면 목록·데이터 흐름을 정리합니다.
2단계
다크 테마와 신호등 상태 규칙을 디자인 토큰으로 정의하고 대시보드·설비 상세·설정 시안을 만듭니다.
3단계
웹 화면을 퍼블리싱해 기존 Supabase 데이터에 붙여 동작을 확인합니다.
4단계
크로스플랫폼으로 모바일 앱을 만들고 푸시 알림·인증·리포트 공유를 연결합니다.
5단계
현장 조건에서 가독성과 조작 단계를 점검하고 디자인 원본·소스코드를 전달합니다.
