About

지도 위에 데이터를 올리는 일

흩어진 기업 정보를 지도 한 장으로 모으면 어디에 무엇이 모여 있는지가 먼저 보입니다. 광맵은 엑셀로 들어온 원본 데이터를 좌표로 바꿔 지도에 올리고, 관리자가 이후에도 직접 등록·수정하며 최신 상태를 유지하도록 설계했습니다. 프로토타입 단계에서 화면과 데이터 흐름을 먼저 확인하고, 이후 확장까지 이어지도록 구조를 잡습니다.

Process

진행 단계

1주차
과업지시서와 원본 엑셀 검토, 요구사항 정의 및 화면 설계 확정
2주차
지도 화면 UI 프로토타이핑, 지도 API 연동과 마커·클러스터링 구현
3주차
엑셀 파싱과 주소 좌표 변환 로직, 관리자 페이지 구축
4주차
상장사 오픈 API 연동, 분류 코드 기준 노출 데이터 정리
인계
소스 코드·기획 파일·DB 덤프·관리자 매뉴얼 전달
