About

찾는 일을 사람에게 맡기지 않습니다

레이스픽은 스포츠 대회 사진을 한 번의 배치로 분류·색인하는 백엔드 파이프라인을 만듭니다. 배번호가 보이는 사진은 검출과 OCR로, 가려진 사진은 얼굴과 의상 벡터로 되찾습니다. 조회 시점에는 추론을 돌리지 않고 미리 만들어 둔 매핑을 읽기 때문에, 참가자 화면이 어떤 방식으로 구현되든 응답은 일정하게 유지됩니다.

Process

진행 단계

1주차
AI 분류/매칭 파이프라인·배치 인프라·API 상세 설계, 대회 샘플 사진으로 배번호 인식 기준선 측정
2~3주차
YOLO 검출 + OCR 판독 + 정규식 필터 구현, Golden Sample 얼굴·의상 벡터 추출 파이프라인 연결
4주차
2-Pass 유사도 필터링 적용 — 가려진 사진 구제와 의상 불일치 배제 임계값 튜닝
5~6주차
Celery+Redis 분산 큐와 다중 GPU 워커 구성, Spot 인스턴스 자동 가동·회수, 매핑 테이블 색인 적재
7주차
관리자·참가자 API 마감, 대용량 부하 테스트, Dockerfile·docker-compose·Swagger 명세와 운영 가이드 인계
