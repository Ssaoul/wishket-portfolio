관리자

점수화에 쓰이는 구간 임계값과 가중치를 화면에서 직접 편집합니다. 저장하면 대시보드·리포트 점수가 즉시 다시 계산됩니다. 개발자가 코드를 고치지 않아도 센터 운영 기준을 조정할 수 있도록 만든 화면입니다.

산식 · 상태 구간 임계값

종합 점수는 4개 영역 점수의 가중 평균입니다. 값을 바꾸면 아래 미리보기가 즉시 갱신됩니다.

영역 가중치

가중치 합이 100이 아니어도 됩니다. 실제 계산에서는 입력된 영역의 가중치 비율로 자동 정규화하며, 측정값이 없는 영역은 제외합니다.

지표별 기준표

양호 구간 안이면 84~100점, 보통 구간이면 60~78점, 구간 밖이면 25~58점으로 환산합니다.

변경 영향 미리보기

현재 편집 중인 기준표로 전체 참가자의 최근 회차 점수를 다시 계산해 기본 기준표와 비교합니다.
