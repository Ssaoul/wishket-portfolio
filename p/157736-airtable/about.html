About

업무 흐름을 먼저 읽고 구조를 짭니다

특허 업무는 기한과 담당이 얽혀 있어, 화면보다 데이터 구조를 먼저 정리해야 합니다. 저희는 기존에 쓰던 Base를 그대로 두고 복사본에서 구조를 다시 짠 뒤, 실제 업무 순서대로 뷰와 자동화를 얹습니다. 넘겨받은 담당자가 직접 수정할 수 있도록 설계 근거와 변경 지점을 문서로 남깁니다.

Process

진행 단계

1주차
기존 Base 분석, 업무 프로세스 정리, DB 스키마 재설계안 확정
2주차
테이블 정규화 및 관계 설정, 과거 데이터 이관·매핑
3주차
권한별 대시보드 구축, 자동화 플로우 10종 이상 구성
4주차
안정화 점검, 구조·자동화 설명서 작성, 인수인계
