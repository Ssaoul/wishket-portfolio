About

만들어 보고 판단하시라고 먼저 만들었습니다

이 화면은 여주 관광 체험 플랫폼 본 구축에 앞서 요청하신 PoC 범위—맞춤형 역사동화 생성, 페이지별 삽화 생성, PDF 전자책 자동 제작, 프롬프트 테스트 환경—를 그대로 화면으로 옮긴 제안용 데모입니다. 어떤 단계에서 시간이 걸리고 어떤 프롬프트가 결과를 바꾸는지 눈으로 확인할 수 있게 구성했습니다. 표시된 내용과 이미지는 합성 데이터이며, 실제 원천 데이터와 요구사항 정의서를 받으면 그 내용으로 교체합니다.

Process

진행 단계

1주
화면 기획과 기본 UI 확정, API 연동 구조와 프롬프트 초안 정리
2주
초대장·프롤로그·동화 텍스트 생성과 페이지별 삽화 생성 연동 테스트
3주
PDF 조판·다운로드 구현, 파이프라인 통합 테스트와 단계별 시간 측정
4주
안전 필터 점검, 프롬프트 세트 정리와 테스트 결과 보고서, 소스 코드 인계
