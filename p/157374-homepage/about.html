About

내부 시스템을 이어받기 전에, 먼저 읽습니다

벤처링크는 신기술사업금융 실무에서 쓰이는 투자실적 취합 시스템을 만들고 다루는 팀입니다. 이 화면들은 담당자가 매일 여는 업무 화면과 그 뒤의 데이터 구조를 어떤 기준으로 들여다보는지 보여주기 위해 구성했습니다. 남이 짜 둔 코드를 이어받을 때는 무엇을 살릴 수 있고 무엇을 다시 세워야 하는지부터 가려내는 일이 먼저라고 봅니다.

Process

진행 단계

1단계
NDA 체결 후 저장소 권한 수령, 실행 환경 구성 및 기능 동작 확인
2단계
코드 구조·데이터베이스 스키마 정독, 계층 경계와 의존 관계 정리
3단계
보안·성능·확장성·유지보수성 관점 점검, 리스크 항목 도출
4단계
영역별 유지/재구축 판단과 개선 우선순위 정리
5단계
진단 결과 및 기술 자문 의견서 전달, 화상 미팅으로 설명
