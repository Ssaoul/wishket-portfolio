About

구축 이후에도 직접 운영하도록

퍼포먼스·콘텐츠·브랜드 마케팅을 함께 굴리는 대행사는 업무 형태가 자주 바뀝니다. 그래서 화면과 항목을 담당자가 직접 늘리고 고칠 수 있는 노코드·로우코드 구성을 택하되, 데이터는 도구별로 흩어지지 않게 하나의 저장소에 모읍니다. 인수인계 시점에는 워크플로우 설정과 연동 명세, 정산 로직 정의서를 운영 매뉴얼과 함께 넘겨 발주처가 스스로 운영을 이어갈 수 있게 합니다.

Process

진행 단계

1주차
업무 규칙 정의와 데이터 구조 설계 — 광고주·프로젝트·캠페인·업무·정산을 단일 저장소 기준으로 정리
2~4주차
노코드·로우코드 플랫폼 배합안 확정, 광고주·프로젝트 관리 화면 구축, 기존 엑셀 양식 정리
5~8주차
네이버·구글·메타 API 연동과 지표 통일 규칙 적용, 제작 일정·업무 관리 기능 구축
9~11주차
정산 계산 로직과 통합 대시보드 구축, 역할별 권한·알림·모바일 조회 화면 대응
12~13주차
엑셀 자료 일괄 이관, 운영 환경 구성과 백업 설정, 사용자 교육과 관리자 권한 이관
