About

반복되는 발급 업무를 파이프라인으로

등기다리는 부동산 문서 발급을 사람이 건별로 누르는 일에서 시스템이 처리하는 일로 옮기는 백엔드를 만듭니다. 공식 공개 API로 해결되는 구간은 API로, 원본 문서가 필요한 구간은 발급 자동화로 나눠 설계해 개발 범위와 운영 비용을 함께 줄입니다. 인증과 캡차처럼 무인화가 제한되는 지점은 감추지 않고, 어디까지 자동이고 어디부터 사람 확인인지 화면과 로그에 남깁니다.

Process

진행 단계

1주차
발급 대상 문서와 용도 확정, 공식 API로 대체 가능한 범위와 발급이 필요한 범위를 나눈 설계 확정
2~3주차
발급 엔진 구현 — 브로커 API 경로와 브라우저 자동화 폴백 경로, 인증 절차 처리 방식 정리
4~5주차
비동기 큐·재시도·주소 정제 적용, Webhook 결과 전송과 저장소 연동
6~7주차
문서 파싱과 항목 구조화, 실패 건 재실행과 운영 콘솔 구성
8주차
API 명세·연동 가이드·운영 매뉴얼 정리 후 인수인계
