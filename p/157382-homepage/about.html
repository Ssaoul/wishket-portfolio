About

수작업으로 나뉘어 있던 계산을 한 곳으로

예측그리드는 이미 검증된 사내 산출 로직을 그대로 시스템에 옮기는 일을 합니다. 새로운 계산 방식을 제안하기보다, 담당자마다 달랐던 실행 순서와 예외 처리를 하나의 코드로 고정해 매월 같은 결과가 나오게 만드는 것이 목표입니다. 이관 전후 값이 일치하는지 항목별로 대조해 확인한 뒤에 넘겨드립니다.

Process

진행 단계

착수 전
산출 로직·예외 규칙 명세와 대조용 엑셀 데이터 수령, DB 접속 정보와 서버 환경 확인
1주차
Aurora 연동과 원천 데이터 수집 구현, 산출 로직을 규칙 단위로 서버 코드로 이식
2주차
월 배치 자동 실행, 조회 웹 페이지와 연·월 조건 검색, 공용 관리자 로그인 구현
납품
이관 전후 대조로 산출 결과 일치 확인, 소스 코드와 시스템·DB 연동 명세서 전달
납품 이후
첫 자동 실행 회차 입회 확인, 예외 규칙 보완 요청 대응
