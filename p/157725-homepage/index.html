제안용 데모 — 발주 내용을 바탕으로 자동 생성한 시안입니다. 발주의 요체인 LOT 단위 매칭(제작설비·레시피·환경값·측정결과 계통도), 장비별 상이한 출력 양식의 파싱과 실패 건 재처리, 원본 무결성과 감사 로그를 실제 화면 구성으로 옮긴 데모입니다. 정상 경로뿐 아니라 파싱 실패·미매칭 LOT·수집 중단 같은 실패 경로를 별도 화면으로 설계해 두었습니다. 브랜드·이미지·수치·사례는 모두 합성이며, 실제 구축 시 발주처 자료로 대체합니다.
