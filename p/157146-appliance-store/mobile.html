브레이크포인트

≥ 1081 px
기본 데스크톱. 최대 폭 1320px, 좌우 여백 72px. 4단 그리드.
≤ 1080 px
태블릿. 4단 → 2단, 가이드 문서의 사이드 목차는 상단 가로 목록으로 전환.
≤ 900 px
모바일 진입. GNB → 햄버거 드로어, 2단 레이아웃 전부 1단, 히어로 분할 해제.
≤ 640 px
소형. 지표 그리드 1열, 구매 버튼 세로 배치, 본문 14.5px 유지.

모바일 규칙

터치 타깃
최소 44 × 44 px. 인접 타깃 간 간격 8 px 이상.
좌우 여백
20 px 고정. 이미지·풀블리드 밴드만 여백을 뚫습니다.
헤더
높이 60 px 고정 · sticky. 스크롤 시 배경만 불투명해집니다.
드로어
전체 화면 오버레이. 열림 상태에서 배경 스크롤 잠금, ESC·링크 클릭 시 닫힘.
이미지
모바일 최대 폭 750 px 기준으로 별도 리사이즈본 사용 권장.
글자 크기
본문 14.5 px · 최소 11 px. 헤드라인은 clamp() 로 뷰포트 비례.
