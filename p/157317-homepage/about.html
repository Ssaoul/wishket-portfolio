About

수기 관리에서 시스템으로

스프레드시트로 하나씩 옮겨 적던 예약을, 고객이 직접 넣고 운영진이 바로 보는 흐름으로 바꿉니다. 고객 화면·관리자 화면·제휴점 화면을 따로 나누되 같은 데이터를 보게 설계했습니다. 인수인계 후 발주자가 직접 손댈 수 있도록 특수한 빌드 환경 없이 표준 구조로 만듭니다.

Process

진행 단계

1단계
요구사항 정의서·화면설계서 확인, 화면 15개 범위와 예외 처리 합의
2단계
데이터 모델·요금표 확정, 기존 4개 언어 리소스와 기기 언어 감지 이관
3단계
고객 화면 6종 구현 — 예약 폼 분기, 결제, 게스트 조회
4단계
관리자 8종·제휴점 1종 구현, 이메일 자동 발송 3종 연결
5단계
실기기 검수 후 인수인계 — 소스·DB·API·배포 문서와 운영 매뉴얼
