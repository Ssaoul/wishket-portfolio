About

화면이 아니라, 붙일 수 있는 모듈을 만듭니다

이 데모는 발주에서 요구한 계산·판정·파일 생성 로직의 인터페이스와 동작을 화면으로 옮겨 본 것입니다. 실제 납품물은 상태를 갖지 않고 민감정보를 저장하지 않는 Python 코드 모듈과 인터페이스 규격서이며, 화면·연동·배포는 범위에 넣지 않았습니다. 세액의 최종 확인은 세무 전문가 검토를 전제로 합니다.

Process

진행 단계

1주
원천자료 실샘플·스키마 확인, 입력·출력·에러 계약 초안과 모듈 호출 단위 설계
2~4주
근로소득·인적용역·겸업 합산·개인지방소득세 계산 로직 구현, 계산 근거 출력 규격 확정
5~6주
자동·수기 판정 로직과 사유 코드 구현, 세법 파라미터 구조·버전 로딩 분리
7주
홈택스·위택스 규격 파일 생성과 사전 검증 구현
8~9주
기존 세무 프로그램 출력물과 대조한 내부 세액 정합 검증, 인터페이스 규격서·호출 예제 정리 후 납품
