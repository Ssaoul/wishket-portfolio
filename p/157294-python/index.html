제안용 데모 — 발주 내용을 바탕으로 자동 생성한 시안입니다. 발주의 네 축(소득·세액 계산, 자동·수기 판정과 사유 반환, 홈택스·위택스 규격 파일 생성과 사전 검증, 귀속연도별 파라미터 버전 관리)을 모듈 호출 단위로 나누고, 단계별 중간값과 적용 파라미터 버전을 담은 계산 근거 출력까지 화면으로 확인할 수 있게 구성했습니다. 단일소득·겸업·수기분기 세 가지 통합 시나리오를 그대로 담아 인터페이스 계약이 어떤 모양인지 코드 없이도 보이도록 했습니다. 브랜드·이미지·수치·사례는 모두 합성이며, 실제 구축 시 발주처 자료로 대체합니다.
