제안용 데모 — 발주 내용을 바탕으로 자동 생성한 시안입니다. 발주의 4개 로직(소득·세액 계산, 홈택스·위택스 규격 파일 생성, 자동·수기 판정과 사유 반환, 귀속연도별 파라미터 로딩)을 모듈 API 카탈로그로 정리하고, 요청하신 세 가지 통합 시나리오(단일소득·겸업·수기분기)와 단계별 계산 근거 출력을 화면으로 구현했습니다. 화면은 스코프 밖이지만 인터페이스 계약과 계산 근거가 어떤 형태로 나오는지 미리 보여드리기 위한 데모입니다. 브랜드·이미지·수치·사례는 모두 합성이며, 실제 구축 시 발주처 자료로 대체합니다.
