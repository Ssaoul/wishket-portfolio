About

현장에서 그대로 쓰이는 채점 파일을 만듭니다

검정랩은 시험 시행 현장의 채점·집계 업무를 엑셀과 매크로로 자동화합니다. 새 프로그램을 배우게 하는 대신, 평가위원이 이미 쓰던 방식 그대로 점수만 입력하면 나머지가 자동으로 처리되도록 설계합니다. 기준표가 바뀌어도 담당자가 직접 수정할 수 있게 규칙을 한 곳에 모아 두는 것을 원칙으로 합니다.

Process

진행 단계

1일차
채점 기준표 원본 분석 — 배점·필수 조건·실격 규칙을 표로 정리하고 확인받습니다
2일차
엑셀 수식 로직 기획 — 입력·산출·판정·취합 시트 구조와 데이터 흐름을 확정합니다
3~4일차
채점 입력 화면과 자동 산출 제작 — 위원 3인 시트, 총점·평균, 실격 판정 표출
5일차
이상 징후 대응 팝업과 본부 취합 시트 연동 — VBA 매크로 작성
6~7일차
태블릿 실기기 구동 점검, 클라우드 동기화 확인, 사용 가이드 문서 전달
